✈️ Integrasi Telegram

Bot polling dijalankan di VPS persistent supaya /task, /laporan, dan auto-laporan 08:00 WIB jalan. Dashboard web ini tetap di Vercel; dua-duanya sinkron lewat Supabase.

Perintah bot:
/task — lihat task aktif
/tambah Judul task — tambah task
/done ID — tandai selesai
/laporan — laporan harian
/rapat Topik — rapat tim AI
/testlaporan — tes kirim laporan ke admin

Status di VPS bisa dicek dengan: systemctl status azira-bot dan log: journalctl -u azira-bot -f
